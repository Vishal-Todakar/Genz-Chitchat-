# 📸 Screenshots Guide

Place the application preview screenshots and GIFs in this directory (`docs/screenshots/`).

## Recommended Screenshots to Add

| File Name | Recommended Size | Description |
|-----------|------------------|-------------|
| `landing.png` | 1920 × 1080 | Modern landing page hero section showing online user counter, interest tags, and theme toggle. |
| `chat-interface.png` | 1920 × 1080 | Active stranger text chat window with typing indicators, emoji picker, and partner tags. |
| `video-chat.png` | 1920 × 1080 | Peer-to-peer WebRTC video stream mode with camera and microphone controls. |
| `otp-verification.png` | 800 × 1000 | 6-box email verification modal with countdown timers and spam folder hints. |
| `razorpay-checkout.png` | 800 × 1000 | Razorpay modal showing UPI apps (GPay, PhonePe, Paytm), QR code, and plan pricing. |
| `demo.gif` | 1280 × 720 (or mp4) | 10–15s animated walkthrough of matchmaking, chatting, and skipping. |

> **Tip:** You can capture crisp screenshots directly using your browser's Developer Tools Device Mode (`Ctrl+Shift+M` / `Cmd+Shift+M`) or desktop screenshot utilities.
